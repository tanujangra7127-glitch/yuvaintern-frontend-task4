
# AccessWeb - Week 4 Project

## Project Title
Enhancing Web Page Performance and Accessibility

## Internship
YuvaIntern - Frontend Web Developer

## Project Overview
AccessWeb is a responsive website developed using
HTML5, CSS3 and JavaScript.

The main objective is to improve webpage performance,
accessibility and user experience.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Responsive Web Design
- ARIA Accessibility

## Features
1. Responsive mobile-friendly layout.
2. Semantic HTML structure.
3. Keyboard accessible navigation.
4. Skip-to-content link.
5. Visible keyboard focus indicators.
6. Lightweight JavaScript.
7. Reduced-motion support.
8. Optimized page structure.

## Project Files
- index.html
- style.css
- script.js
- README.md

## How to Run
1. Download the project files.
2. Keep all four files in one folder.
3. Open index.html in a browser.
4. Test the navigation on desktop and mobile.

## Performance Testing
Use Google Lighthouse to check:
- Performance
- Accessibility
- Best Practices
- SEO

Record actual test results before submission.

## Conclusion
This project demonstrates how responsive
design, accessibility and performance practices
can improve the overall web experience.
